Notes: Distance-time graphs

distance-time graph

A graph of distance (y) against time (x). For example: a journey to school.

gradient

How steep a line is: rise / run. For example: steeper = faster.

stationary

Not moving. For example: a flat line.

constant speed

The same speed all the time. For example: a straight sloping line.

axis

One of the two lines a graph is drawn on. For example: time on the x-axis.

plot

Mark data points on a graph. For example: (4 s, 20 m).

Key words

distance-time graphdistance on y, time on x
gradientrise / run; equals speed
stationarynot moving; flat line
constant speedstraight sloping line
tangenta line touching a curve at one point
