Notes: Three types of adaptation

structural adaptation

A body part or shape. For example: thick fur, long neck.

behavioural adaptation

Something an organism does. For example: migration, hibernation.

functional adaptation

A process inside the body. For example: camel making very little urine.

camouflage

Colours or patterns that blend into the background. For example: arctic fox in snow.

hibernation

A deep sleep through winter to save energy. For example: hedgehogs.

migration

Moving long distances with the seasons. For example: arctic tern.

camouflage

Colours or patterns that help an organism blend in, so predators or prey do not see it. For example: a moth on tree bark.
