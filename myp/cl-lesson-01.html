Notes: Why we sort things

classify

Sort things into groups by the features they share. For example: animals with feathers are birds.

feature

A property you can observe, such as colour, shape or number of legs. For example: six legs.

group

Things that share one or more features. For example: all the red buttons.

pattern

Something that repeats, so we can predict it. For example: all fish have fins.

living

A thing that is alive or was once alive. For example: a frog.

non-living

A thing that has never been alive. For example: a pebble.
