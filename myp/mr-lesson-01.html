Notes: Elements and the periodic table

atom

The smallest particle of an element. For example: a gold atom.

element

A substance made of only one type of atom. For example: copper, oxygen.

compound

Two or more elements chemically joined. For example: water, H2O.

symbol

One or two letters that stand for an element. For example: Fe for iron.

group

A column of the periodic table. For example: group 1: alkali metals.

metalloid

An element with some metal and some non-metal properties. For example: silicon.

metalloid

An element with some properties of metals and some of non-metals. For example: silicon, used in computer chips.
