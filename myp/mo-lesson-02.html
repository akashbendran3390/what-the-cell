Notes: Speed and velocity

speed

Distance travelled per unit time. For example: 12 m/s.

velocity

Speed in a given direction. For example: 12 m/s north.

average speed

Total distance / total time. For example: a whole journey.

instantaneous speed

The speed at one moment. For example: the speedometer reading.

metre per second

The SI unit of speed, m/s. For example: walking: about 1.4 m/s.

kilometre per hour

Km/h; used on road signs. For example: city limit 50 km/h.
