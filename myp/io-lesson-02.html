Notes: Electron shells

shell

An energy level around the nucleus that holds electrons. For example: the first shell holds 2.

electron arrangement

How many electrons are in each shell. For example: sodium is 2,8,1.

outer electrons

Electrons in the outermost shell. For example: sodium has 1.

group

A column; elements with the same number of outer electrons. For example: group 1 has 1 outer electron.

noble gas

Group 0 element with a full outer shell; very unreactive. For example: neon, argon.

stable

Not likely to change or react. For example: a full outer shell.
